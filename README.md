# Front-End-Agrinho-2026

Link para o projeto: https://mateussilva-matt.github.io/Front-End-Agrinho-2026/

O projeto foi feito utilizando de três linguagens de programação sendo elas Java Script, CSS e html. O principal intuito do projeto é a demonstração e simulação de um serviço especializado na distribuição de serviços com o intuito de modernizar o agro de modo sustentável.

# Funcionamento do Projeto:

O projeto funciona como a página de entrada de um site a qual possui um espaço para simular o investimento. A função dessa simulação é feita de modo simples, uma barra movivel a qual você pode escolher os hectares que deseja emular e assim conseque saber o valor do investimento e o ROI estimado anual. Os hectares vão de 10 hectares até 5000 hectares.

# *O principal objetivo para esse projeto é a formulação de uma ideia de um serviço de internet com a oferta de modernização e sustentabilidade para o agronegócio.*
